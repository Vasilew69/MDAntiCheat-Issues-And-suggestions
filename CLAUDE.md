# MDAntiCheat issues and suggestions

Public issue tracker for the MDAntiCheat plugin (code lives in Vasilew69/AntiCheat). No code here.

- Issue forms: `.github/ISSUE_TEMPLATE/`. Labels: `.github/labels.json`, synced by
  `.github/workflows/labels.yml` on push to `main`.
- New issues go to the Blocksmith project board via `.github/workflows/add-to-project.yml`
  (needs the `PROJECT_TOKEN` secret).
- Keep the forms in step with the plugin: when a check is added or renamed in Vasilew69/AntiCheat,
  update the Check dropdown in `1-false_positive.yml` and the README's version range.
